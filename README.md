# TODO-List-app
A simple and responsive Todo List application built using **HTML**, **CSS**, and **JavaScript**. It allows users to add and remove tasks easily in a clean and minimal UI.

# Features

- Add new tasks
- Remove tasks
- Press `Enter` to add tasks
- Clean and responsive design
